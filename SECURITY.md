# Seguridad

## Reportar vulnerabilidades
Reporta problemas de seguridad en privado (no uses issues públicas). Proporciona pasos para reproducir y alcance.

## Principios
- Solo lectura por defecto; sin modificaciones sin confirmación.
- Catálogo cerrado, sin shell para acciones.
- Redacción de rutas/usuario antes de enviar al proveedor.
- Servidor solo en localhost (127.0.0.1).
- Tratar datos como no confiables.
